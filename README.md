# منصة البساطة (Al-Basata Platform)

موقع ثابت (Static) لمدرس تاريخ: **أولى ثانوي عام (مصر الحضارة)** و**تانية ثانوي بكالوريا (التاريخ الوطني)**.
HTML/CSS/JS عادي، **من غير Build ولا npm للتشغيل**، ومجاني على GitHub Pages.

## النشر على GitHub Pages
1. ارفع كل محتويات الفولدر ده (index.html و css و js و data و sw.js ...) على الـ Repository.
2. Settings ثم Pages ثم Deploy from a branch ثم `main` و `/ (root)` ثم Save.
3. الرابط: `https://USERNAME.github.io/REPO/` (المنصة بتشتغل تحت أي مسار فرعي).

## هيكل الملفات
```
index.html            الصفحة الوحيدة (Hash routing)
css/app.css           التصميم (دفتر المدرسة: أزرق مسطّر + هامش أحمر + ختم)
js/main.js            التشغيل والتنقل | js/router.js | js/ui.js (بناء DOM آمن)
js/data/              loader (تحميل + رسائل أخطاء ودّية) | validator | store (التقدّم)
js/views/             الرئيسية، الكورس، الدرس، الكويز، المراجعة، البحث، المدرس، قائمة التجهيز
data/config.json      اسم المدرس، الواتساب، المواعيد
data/courses.json     المنهج (27 درس بأسماء مطابقة لما اتوفر)
data/lessons/<id>.json  محتوى كل درس (ملف لكل درس)
sw.js + manifest      العمل بدون نت + التثبيت كتطبيق
tests/unit            41 اختبار (node)      tests/e2e   46 فحص في متصفح حقيقي (Python)
```

## الاختبارات
```bash
npm install && npm test              # اختبارات الوحدات
pip install playwright && python -m playwright install chromium
python tests/e2e/run_e2e.py          # متصفح حقيقي: موبايل/ديسكتوب، أوفلاين، أخطاء JSON، تباين الألوان، الأداء
```
GitHub Actions بيشغلهم تلقائيًا مع كل رفع (`.github/workflows/test.yml`).

## قرارات أمان
- مفيش `innerHTML` في الكود: أي نص من ملفات JSON بيتعرض كنص فقط (فيه اختبار بيمنع رجوعه).
- CSP صارم (بدون inline scripts/styles/eval)، الروابط `https` أو داخل الموقع فقط.
- الفيديو: `youtube-nocookie` ومش بيتحمّل غير بعد الضغط، وكود الفيديو 11 حرف بالظبط.
- مفيش مفاتيح ولا تتبّع ولا بيانات طلاب: التقدّم على جهاز الطالب فقط (localStorage) ومعاه تصدير/استرجاع بملف.
- الـ Repository Public: **متحطش أي مفتاح سري**. لو محتاج Backend لاحقًا، المفاتيح تعدي من وسيط (Cloudflare Worker) مش من الصفحة.

## نشر تحديث
غيّر أي ملف ثم ارفعه. لو غيّرت ملفات الموقع نفسها (js/css) زوّد رقم `VERSION` في `sw.js` علشان الطلاب ياخدوا النسخة الجديدة (بتظهر لهم رسالة "حدّث دلوقتي"). ملفات `data/` بتتحدّث لوحدها.

## حدود معروفة (بصراحة)
- الترم التاني من تانية بكالوريا **فاضي عمدًا** لحد ما المدرس يوفر المنهج.
- الأسماء متأكد منها من توزيعات منشورة وقيد تأكيد المدرس على كتاب الوزارة (خصوصًا "مرتكزات" في ب/و3/د3).
- محتوى الدرسين النموذجيين "مسودة" ومحتاج مراجعة المدرس قبل الاعتماد.
- خط العناوين (Aref Ruqaa) بيتحمّل من Google Fonts بعد الصفحة؛ لو عايز صفر اتصال خارجي استضفه عندك.
- مفيش تسجيل دخول ولا متابعة الطلاب من عند المدرس (ده المرحلة 3 بـ Supabase + سياسات RLS).
